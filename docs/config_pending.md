# Незаполненные значения config.yaml

Сгенерировано `tools/validate_config.py --checklist`; не редактировать руками — файл перезаписывается.

Заполнять значениями, которые реально видны на странице. К каждому — откуда взято и когда. Если значение относится к конкретному аккаунту, а не к базовому тарифу, это надо написать.

## Комиссии тейкера
